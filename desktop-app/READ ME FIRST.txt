TEAM BOARD  (team board + DroneForge Pro ERP in one program)
============================================================

INSTALL
  1. Right-click TeamBoard-Windows.zip and choose "Extract All".
     Do NOT run the program from inside the zip.
  2. Move the extracted "Team Board-win32-x64" folder somewhere permanent,
     for example C:\TeamBoard
  3. Right-click "Team Board.exe" > Send to > Desktop (create shortcut).

START
  Double-click "Team Board.exe". The first time, Windows may ask:
   - "Windows protected your PC": click "More info", then "Run anyway".
   - Windows Firewall: click "Allow", so phones and laptops on the office
     network can open the board.

YOUR DATA
  Everything is saved automatically, within a second of each change, in:
      Documents\Team Board
  It stays there when you close the program, restart the PC, or install a
  newer version of Team Board. The first time version 1.1 starts, it moves
  any data from the old place (the "data" folder next to the exe) into it.

  Menu > Team Board > "Where is my data saved?" shows the folder, the number
  of records and the last save time.
  If saving ever fails, a red bar appears at the bottom of the screen.
  Don't close the program then; tell whoever looks after it.

  Inside Documents\Team Board:
    store.json        all board and ERP data
    store.prev.json   the copy before the last save
    backups\          one full copy per day, last 60 days
    files\            files attached to tasks
    logs\             technical log, useful if something goes wrong
  Copy the whole "Team Board" folder from Documents to a USB stick or cloud
  drive now and then.

NEW IN VERSION 1.2
  - Production tab: units made per day, finished products, materials needed
    for all open orders, "runs out in N days", output per person and per
    product, and Export to Excel.
  - Reported units now take materials out of ERP stock (by the bill of
    materials) and add finished products. Deleting a report puts them back.
    (Admin > Settings can turn this off.)
  - My work: the phone page for workers. +1 / +5 buttons, "Report...",
    "I'm blocked". Phones open it automatically.
  - Stand-up button: goes through the team one person at a time
    (yesterday / today / blockers) with a timer. Arrow keys move on.
  - TV mode has a Production slide, and a red alert with a sound when a
    task becomes blocked ("Alerts on/off" button in TV mode).
  - Admin > Templates: work steps, standard hours per unit and quality
    check items for each ERP product. New tasks get them automatically.
  - Quality check when a product task is marked as done. The result goes
    to the ERP's Quality tab.
  - Admin > Backups: an extra daily copy to a USB stick or cloud folder.
  - Admin > Settings: a password for access from outside the office
    network (blocked until you set one).
  - Cards can be dragged on a touchscreen: press and hold, then drag.

UPDATES FROM NOW ON
  Later updates come as ONE small file (about 1.5 MB) named like
  "Team Board update 1.2.1.asar". In Team Board: Help > Install update
  from file, choose the file, click "Restart now". If an update ever
  fails to start, the program sets it aside and keeps working.
  Help > "Go back to the previous version" undoes an update.

ON THE TV
  F11 = full screen. "TV mode" on the board rotates the overview, who's
  working on what, the board, Top 3 and the latest issues.
  Menu > Team Board > "Start with Windows" opens it at login.
  Set Windows Settings > Power > Sleep to "Never" on this PC.

FIRST SET-UP
  1. Tap "Locked. Tap to sign in", enter your name, choose a PIN (admin).
  2. Admin tab > Members > Add member, for each worker.

MOVE YOUR EXISTING ERP DATA IN (once)
  Open the old DroneForge_Pro_EU.html in your browser > Reports >
  Export Data. Then in Team Board: ERP tab > Reports > Import Data.

OTHER COMPUTERS AND PHONES
  Menu > Help > "Phones and other computers" shows the address, for
  example http://192.168.1.20:8080 . Open it in a browser on any device on
  the same network. Team Board must be running on this PC.

TO RESTORE A DAILY BACKUP
  Quit the program. In Documents\Team Board, rename store.json to
  store-broken.json. Copy the backup you want from backups\ into the
  folder and rename it to store.json. Start the program.
